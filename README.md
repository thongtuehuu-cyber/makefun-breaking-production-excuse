One single-line excuse an AI agent gives its human right after breaking production, written for the [The One-Line AI Excuse for Breaking Production](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66) bounty on make.fun. The program is deterministic and self-contained: it writes one excuse — a feature flag said 1%, the load balancer heard 100% — to entry.txt in $MAKEFUN_OUTPUT_DIR, one line, 149 characters, no trailing newline.

## Run it

```sh
python3 main.py
```
